# Gestion de Notes Personnelles

## Description
Une application web simple permettant de gérer vos notes personnelles.  
Vous pouvez créer, modifier, supprimer et consulter vos notes dans un environnement sécurisé et intuitif.

## Technologies utilisées
- **Backend :** PHP orienté objet (POO)
- **Frontend :** HTML, CSS
- **Base de données :** MySQL

## Fonctionnalités
- Authentification des utilisateurs
- Création, modification et suppression de notes
- Consultation de toutes les notes
- Dashboard bien détaillé
- Espace compte
- Interface simple et responsive
