## À propos du projet

Une application web simple et intuitive pour gérer vos **notes personnelles**. Ce projet a été développé dans le but de **réviser les bases de la Programmation Orientée Objet (POO) en PHP**.

L'application permet de créer, modifier, supprimer et consulter des notes dans un environnement sécurisé avec authentification utilisateur.

---

## Objectifs pédagogiques

- Maîtriser les concepts fondamentaux de la **POO en PHP**
- Comprendre l'architecture **MVC** (Modèle-Vue-Contrôleur)
- Gérer l'**authentification** et les sessions utilisateur
- Interagir avec une base de données **MySQL** via PDO
- Développer une interface **responsive** avec HTML/CSS

---

## Fonctionnalités

### Authentification
- Inscription utilisateur
- Connexion / Déconnexion sécurisée
- Espace compte personnel

### Gestion des notes
- Créer une nouvelle note (titre + contenu)
- Modifier une note existante
- Consulter toutes ses notes
- Supprimer une note
- Dashboard détaillé avec statistiques

## Technologies utilisées

| Technologie | Rôle |
|-------------|------|
| **PHP 8.x (POO)** | Backend & logique métier |
| **MySQL** | Base de données |

| **CSS3** | Styles et mise en page |
| **PDO** | Accès sécurisé à la base de données |
